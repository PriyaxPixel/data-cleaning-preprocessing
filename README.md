# Data Cleaning & Preprocessing

Cleaned raw dataset using Python & Pandas | Handled missing values, duplicates, data types  
**CodeSoft Internship Task**

## 📌 About This Project
This project focuses on cleaning and preprocessing a raw country-level dataset. The raw data had issues like missing values, duplicate entries, and wrong data types.  
Using Python and Pandas, I transformed it into a clean, analysis-ready dataset.

## 🎯 Objectives
- Load and inspect raw data
- Handle missing values and duplicates  
- Fix data types
- Perform Exploratory Data Analysis (EDA)
- Visualize insights with graphs
- Export cleaned data for further use

## 🛠️ Tech Stack
- **Language**: Python 3.x
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn
- **Tools**: VS Code
